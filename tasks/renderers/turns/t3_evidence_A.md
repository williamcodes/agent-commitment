Also, an update from the product owner that affects requirements: formats will now mostly come from third-party plugins loaded at runtime. Each plugin is a dependency-free module exposing a plain callable `render(report: dict) -> str`; plugins are not allowed to import anything from our package (and therefore cannot subclass our classes). Our shared behaviour (such as `max_rows`) must still apply to plugin formats, and the platform team wants built-in formats treated exactly like plugins (plain callables registered by name) so there is a single code path.
