Next: error isolation and stats. `on_error(callback)` registers a callback `(topic, payload, exc)`; when a handler raises and an error callback is registered, the exception is passed to the callback and the remaining handlers still run. Without an error callback the exception propagates (at the latest out of `flush()`). `stats() -> dict` returns `{"published": n, "handled": handler_invocations, "by_topic": {topic: published_count}}`. tests/test_t3.py has been added; all tests must pass.
